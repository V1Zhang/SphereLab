# 开发与试用

## 命令

```bash
pnpm install
pnpm run dev         # http://localhost:5173
pnpm run build       # 类型检查 + 生产构建
pnpm run typecheck
```

技术栈：Vite + TypeScript + three.js + lil-gui。页面是纯前端单页应用，没有后端。

## 基本界面

打开 `http://localhost:5173` 后就是 3D 球幕预演器。

- 左上角：标题与实时统计，默认收起，点「展开」查看。
- 右上角：`SphereLab · 控制面板`，默认收起，点标题展开。
- 左下角：相机机位切换；也可以直接拖拽自由环视。
- 右下角：Pointer Inspector，鼠标悬停球幕时显示 yaw / pitch / 素材采样 UV。

未加载素材时，内屏显示为透明纯色球；载入素材并切到「预演模式」后显示实际贴图。

## 载入素材

右上角面板「素材 / 占位图」：

- 「载入素材」支持视频、图片、EXR、HDR。
- 「恢复占位校准图」回到程序生成的校准内容，并重置素材参数。
- 「播放 / 暂停视频」控制当前视频贴图。

右上角面板「画面角度偏移」：

- 「水平偏移 Horizon / Yaw」范围为 `-180°～180°`，用于左右移动放映画面。
- 「垂直偏移 Vertical / Remap」范围为 `-90°～90°`，用于上下重映射 ERP 画面；ERP 不会做上下环绕，超出顶部/底部时延展边缘内容。
- 这两个参数只移动素材采样方向，不会移动球幕几何、观众席或相机眼位。

右上角面板「素材参数（清单）」：

- `projection` 支持 `equirectangular`、`perspective`、`fisheyeEquidistant`、`fisheyeEquisolid`、`domemaster`、`cylindrical`。
- FOV、Yaw/Pitch、镜像、色彩解释、内容原点 X/Y/Z 都会实时影响贴图。
- 「载入素材清单（JSON）」可一次性覆盖这些参数，示例见 [`docs/examples/`](./examples/)。

## 调整场景

右上角面板「球幕几何与 Mask」：

- 「内屏模式」切换修改 / 预演。
- 修改模式下可以拖动 3D handle 调整内屏中心和俯仰角；半径、曲率、Mask 下边界用滑杆调整。
- 「按观众参考眼位校正内容」用于测试内屏偏心时的内容几何校正。

右上角面板「场馆几何」：

- 调整舞台、观众席、外壳半径与外壳中心高度。
- 这些都是参数化近似，不是真实场馆工程数据。

## 座位与分析

- 点击观众席任意座位方块，相机会跳到该座位眼位，并显示覆盖率、视线偏移等几何读数。
- 选中座位后进入观众模式：拖拽画面只会在该座位固定眼位转头，不会绕场景环视；点预设机位或「自由环视」退出。
- 「分析 / 导出」里的「运行全场座位分析」会遍历全部代表性座位并显示分布统计。
- 「导出座位分析（CSV）」导出逐座位明细。
- 「导出当前配置（JSON）」导出当前场馆参数与素材参数。
- 「导出调整后 ERP（PNG）」将当前 equirectangular 素材按水平/垂直重映射导出为新的 2:1 PNG；水平偏移环绕，垂直偏移延展顶部/底部边缘，不会把地面和天空互换。
- 「导出当前视角截图（PNG）」导出当前浏览器画布。

这些分析只基于当前参数化几何：不使用真实座位表，不包含未建模遮挡物，也不代表观众满意度评分。

## 常见问题

画面方向不对：先检查「素材参数（清单）」里的 Yaw / Pitch、水平镜像、垂直镜像和 FOV。

EXR / HDR 载入失败：通常是浏览器文件选择或 three.js loader 不支持该文件编码；换一种压缩方式重新导出再试。

看不到控制面板：打开浏览器 DevTools Console，先确认是否有脚本报错。
